Sección I: Comandos Básicos de Sistema

Esta sección cubre la navegación y manipulación de archivos y directorios.

1.1. Comandos de Listado (ls)

El comando ls permite visualizar el contenido de los directorios.

  • Variantes: ls, ls -ruta, ls -l (una fila), ls -a (ocultos), ls -h (legible), ls -t (por tiempo), ls -r (reversa), ls -R (recursivo), ls -S (tamaño), ls -i (inodes), ls -la, ls -lh, ls -ltr, ls -ld, ls --color, ls -F, ls -x, ls -C, ls -u, ls -cr.
  • Uso de Comodines: ls *.gif, ls archivo?, ls [A-Z], ls [a-z0-9], ls jose [113], ls -(sS) *.l?t.

Ejemplos:


ls -la /home/usuario # Lista todos los archivos con detalles.
ls [a-z]* # Lista archivos que empiecen con letra minuscula.
ls -R /etc # Lista recursivamente el directorio de configuracion.

1.2. Navegación y Lectura (cd, cat, more, less)

  • cd: cd, cd directorio, cd .., cd ../foo, cd /, cd ../.., cd /.
  • cat: cat, cat archivo1 archivo2, cat archivo1 archivo2 > archivo3 (unir), cat archivo1 archivo2 archivo3 >> archivo3 (añadir), cat carta.txt.

Visualizadores: more <fichero>, less carta.txt, ls | less.

Ejemplos:


cd /var/log && cat syslog # Entra al directorio y muestra el log.
cat parte1.txt parte2.txt > final.txt # Une dos archivos.

1.3. Gestión de Archivos (cp, mv, rm)

  • cp (copiar): Opciones -d, -f, -i, -l, -p, -s, -R, -v.
  • mv (mover/renombrar): Opciones -f, -i, -v, -u.
  • rm (borrar): Opciones -f, -i, -r, -R, -v.

Ejemplos:


cp -r /orig /dest # Copia directorios de forma recursiva.
mv archivo1.txt nuevo_nombre.txt # Renombra un archivo.
rm -rf directorio_viejo # Borra un directorio y su contenido sin preguntar.

1.4. Creación de Directorios (mkdir, rmdir)

  • mkdir: mkdir trabajo, mkdir -p /home/jose/test.
  • rmdir: rmdir subdir, rmdir -r namedir.

Sección II: Comandos Avanzados y Filtros

2.1. Ordenamiento y Búsqueda (sort, grep)

  • sort: sort fichero, sort -o f1 f1, sort -r (reverso), sort -n (numérico). Opciones: -f, -t, -u, -c, -k.
  • grep: Busca patrones. Opciones: -c, -i, -n, -v, -l.

Ejemplos:


sort -n edades.txt # Ordena un archivo por numeros.
grep -i "error" /var/log/syslog # Busca "error" ignorando mayusculas.
grep -v "proceso" lista.txt # Muestra lineas que NO contienen "proceso".

2.2. Localización y Procesamiento (find, cut, ln, ps)

  • find: find . -name "*.txt".
  • cut: Extrae columnas. cut -f 1 -d ':' /etc/passwd.
  • ln: Crea enlaces. ln -s origen destino (simbólico).
  • ps: Procesos. Opciones aux, l, u, j.

2.3. Utilidades de Texto (head, tail, wc, touch, uniq)

  • head/tail: Primeras o últimas N líneas (-n).
  • wc: Cuenta palabras (-w), líneas (-l) o caracteres (-c).
  • touch: Crea archivos vacíos o cambia marcas de tiempo.
  • uniq: Omite líneas repetidas adyacentes.

2.4. Permisos y Administración (chmod, chown, alias)

  • chmod: Cambia permisos. chmod 755 script.sh, chmod u+x archivo.
  • chown/chgrp: Cambia propietario y grupo.

Sección III: Programación Shell (Bash Scripting)

Un script es un archivo ejecutable que contiene una serie de comandos.

3.1. Estructura Básica

Todo script debe comenzar con el Shebang: #!/bin/bash.

3.2. Variables y Argumentos


nombre="Usuario"
echo "Hola $nombre"
echo "Primer argumento: $1"

3.3. Estructuras de Control

Estructura If-Else:


if [ -f "archivo.txt" ]; then
  echo "El archivo existe"
else
  echo "No encontrado"
fi

Bucle For (Instalador sencillo):


for paquete in git vim curl; do
  sudo apt install $paquete
done

Bucle While (Backup Automatizado):


while [ $# -gt 0 ]; do
  tar -czf "backup_$1.tar.gz" "$1"
  shift
done

Sección IV: Resolución de Errores Comunes

4.1. Permission Denied

Identificación: El sistema impide ejecutar o leer un archivo.

  1. Falta sudo: Ejecutar con sudo !!.
  2. Sin permisos ejecución: Usar chmod +x archivo.
  3. Propietario incorrecto: Corregir con chown.
  4. Partición montada solo lectura: Revisar mount.
  5. Protección de directorio: Revisar permisos del directorio padre.

4.2. Command Not Found

Identificación: El comando no está instalado o no está en el PATH.

  1. Error tipográfico: Escribir sl en vez de ls.
  2. No instalado: Usar apt install [comando].
  3. PATH incompleto: Agregar ruta a .bashrc.
  4. Script local: Usar ./script.sh en lugar de script.sh.

Sección V: Flujo de Datos y Operadores

En Linux, todo se trata de flujos de datos.

  • stdin (0): Entrada estándar (teclado).
  • stdout (1): Salida estándar (pantalla).
  • stderr (2): Salida de errores.

5.1. Operadores de Redirección

  • | (Pipe): Pasa la salida de un comando a la entrada de otro.
  • > (Sobre-escribir): Envía salida a un archivo borrando lo anterior.
  • >> (Añadir): Envía salida al final de un archivo.
  • 2> (Redirigir errores): Captura solo los mensajes de error.

5.2. Ejemplos de Combinación

  1. Filtro de combinación: ls /etc | grep "network" (Busca archivos específicos en /etc).
  2. Conteo y ordenamiento: cat lista.txt | sort | uniq | wc -l (Cuenta líneas únicas ordenadas).
  3. Registro de errores: ls /dirinexistente2 > errores.log (Guarda el error en un log).
